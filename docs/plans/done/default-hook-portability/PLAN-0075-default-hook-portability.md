## Purpose / Big Picture

Implement the approved portable default hooks and validate a local rollout for Claude and Codex, without changing unrelated guard policies. Users should receive actionable provider-appropriate guidance, protected-path checks for native patches, side-effect-free move inspection, and working Stop attention in tmux. Unit tests, real compiled-binary Docker tests, and bounded native smoke demonstrate the result. Only the current documentation worker's assignment stops at planning; the parent coordinates all implementation and authorized local deployment.

## Product Context

**Problem we are solving:** Provider-specific guidance and hook behavior do not travel safely between Claude and Codex. **Metrics this may affect:** Fewer incorrect recommendations, fewer avoidable refusals, and safer local trials; no new product metrics are invented. **Feature alignment:** Preserve the original curation intent (focused safety hooks, abstention on nonmatches, configurable rules) while accounting for the later split into core and project packs. This is hook content portability, not a runtime, permissions, or event-system redesign.
